# 易經占筮與研習記事系統

一套為易經研習者與占卜愛好者量身打造的現代化紀錄與起卦應用系統。

🌐 **線上免安裝網址（手機/平板/電腦通用）**：
👉 **https://coachsunny.github.io/iching/**

---

## 🌟 系統特色

1. **完整涵蓋十三項占卜紀錄**：
   - 1. 占卜日期（自動精確至日時分，支援開新卦即時更新）
   - 2. 占卜主題（所問事項、決策問題）
   - 3. 占卜者（問卦人）
   - 4. 本卦卦名（含六十四卦宮名、卦象符號與內外卦象）
   - 5. 動爻（精確標記老陽、老陰變爻，如：初九、六二）
   - 6. 之卦卦名（依動爻自動推衍變卦）
   - 7. 本卦卦詞（周易原典彖辭與大象傳）
   - 8. 本卦卦意（白話詳解、處境解析、適合/不宜作為、時機建議）
   - 9. 動爻爻詞（精選所有動爻之周易原典爻辭與小象傳）
   - 10. 動爻爻義（動爻深層白話解析、時機吉凶判定、行動指引）
   - 11. 之卦卦詞（演變趨向原典判辭）
   - 12. 之卦卦意（變卦未來發展白話分析）
   - 13. 心得記錄（支援個人體悟自由輸入、內建感悟/行動方針/事後覆盤範本）

2. **多元正統起卦方式**：
   - **三枚銅錢法**：經典金錢課算法，可逐爻投擲（具備銅錢翻轉與正反面計分動畫），或一秒一鍵起卦。
   - **實體銅錢/蓍草輸入**：若您在家使用實體銅錢、蓍草或米卦，可直接點選初爻至上爻之數值（6 老陰、7 少陽、8 少陰、9 老陽）。
   - **直接指定本卦與動爻**：供研究與覆盤使用，直選 64 卦並勾選動爻。
   - **梅花易數（報數起卦）**：輸入三個數字，自動排盤出卦與動爻。

3. **內建朱熹《易學啟蒙》解卦指南**：
   - 依據動爻數量（0動爻至6動爻），系統自動提示此次斷卦重心（看本卦卦辭、特定動爻、或是之卦）。

4. **永久留存與多重存檔**：
   - **GitHub Pages 雲端存檔**：直接存在手機/電腦瀏覽器本地空間（LocalStorage），關機不遺失，支援一鍵「📥 匯出備份 (JSON)」與「📥 匯入紀錄 (JSON)」跨裝置無縫同步。
   - **本機檔案輸出**：每筆紀錄可匯出為標準 Markdown 檔案（.md），方便貼入 Obsidian、Notion 或列印/轉存 PDF。
   - **隱私安全保證**：`.gitignore` 預設排除 `records/*.md`，個人私密占卦心得絕對不會被推送到公開 GitHub 庫。

## 🚀 使用方式

### 方式一：直接使用 GitHub Pages 線上版（最方便、手機隨身帶）
直接用手機、平板或電腦打開：
🔗 **https://coachsunny.github.io/iching/**
*(免開伺服器、免打指令，手機瀏覽器可點「加入主畫面」當 APP 使用)*

### 方式二：本機伺服器自動啟動（電腦硬碟直接存檔）
- 若希望每次按儲存時自動在 `D:\易經\records\` 產生實體檔案：
  - 雙擊執行 **`設定開機自動在背景啟動.bat`** 即可，以後電腦開機在背景自動運作，直接開啟 `http://localhost:3000` 即可使用。
