# 易經占筮與研習記事系統

一套為易經研習者與占卜愛好者量身打造的現代化本地端紀錄與起卦應用系統。

---

## 🌟 系統特色

1. **完整涵蓋十三項占卜紀錄**：
   - 1. 占卜日期（自動精確至日時分）
   - 2. 占卜主題（所問事項、決策問題）
   - 3. 占卜者（問卦人）
   - 4. 本卦卦名（含六十四卦宮名、卦象符號與內外卦象）
   - 5. 動爻（精確標記老陽、老陰變爻，如：初九、六二）
   - 6. 之卦卦名（依動爻自動推衍變卦）
   - 7. 本卦卦詞（周易原典彖辭與大象傳）
   - 8. 本卦卦意（白話詳解、處境解析、適合/不宜作為、時機建議）
   - 9. 動爻爻詞（精選所有動爻之周易原典爻辭與小象傳）
   - 10. 動爻爻義（動爻深層白話解析、時機吉凶判定、行動指引）
   - 11. 之卦卦詞（演變趨向原典判辭）
   - 12. 之卦卦意（變卦未來發展白話分析）
   - 13. 心得記錄（支援個人體悟自由輸入、內建感悟/行動方針/事後覆盤範本）

2. **多元正統起卦方式**：
   - **三枚銅錢法**：經典金錢課算法，可逐爻投擲（具備銅錢翻轉與正反面計分動畫），或一秒一鍵起卦。
   - **實體銅錢/蓍草輸入**：若您在家使用實體銅錢、蓍草或米卦，可直接點選初爻至上爻之數值（6 老陰、7 少陽、8 少陰、9 老陽）。
   - **直接指定本卦與動爻**：供研究與覆盤使用，直選 64 卦並勾選動爻。
   - **梅花易數（報數起卦）**：輸入三個數字，自動排盤出卦與動爻。

3. **內建朱熹《易學啟蒙》解卦指南**：
   - 依據動爻數量（0動爻至6動爻），系統自動提示此次斷卦重心（看本卦卦辭、特定動爻、或是之卦）。

4. **永久留存與雙重存檔**：
   - 每筆紀錄皆會在 `records/` 資料夾自動生成標準格式的優雅 Markdown 檔案（如：`2026-10-06_王先生_事業求職_水雷屯之水天需.md`）。
   - 系統內部資料庫與瀏覽器本地快取同步雙重備份。
   - 支援一鍵複製為 Markdown（可直接貼入 Notion、Obsidian、筆記本、通訊軟體）、下載檔案、列印或轉存 PDF。

## 🚀 啟動方式

### 方法一：雙擊捷徑啟動（最簡單）
直接在資料夾中雙擊 **`啟動易經占卜.bat`**，即可自動開啟本地伺服器並在預設瀏覽器中打開介面。

### 方法二：指令列啟動
開啟 PowerShell 或 命令提示字元，輸入：
```bash
node server.js
```
接著在瀏覽器打開：`http://localhost:3000`
